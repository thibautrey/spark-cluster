Advanced connection

Choose roles and connect the fabric

Select one head. For multiple Sparks, run NVIDIA Sync → Settings → Cluster Assistant, then leave fabric IPv4 blank for automatic detection, or enter it from Sync if several links are active. Four Sparks support either a physical ring or a 200G switch.

A switch enables the lowest-latency collectives and independent model pools. Four Sparks can also run efficiently as a switchless NCCL ring.
One-time access preparation

Use an existing SSH key on the bootstrap host and an account with noninteractive sudo. Verify each displayed fingerprint on its device with ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub. Passwords and private keys are never requested in this page.
