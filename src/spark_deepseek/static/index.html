Find machines on your LAN

Automatic discovery uses mDNS. You can also search a private /24 subnet or add an IPv4 address. GPU compatibility is checked after SSH pairing.

Power on your Sparks and connect them to the same management network.

Discover machines to begin.

Choose roles and connect the fabric

Select one head. For multiple Sparks, run NVIDIA Sync → Settings → Cluster Assistant, then leave fabric IPv4 blank for automatic detection, or enter it from Sync if several links are active. Four Sparks require a switch.

One-time access preparation

Use an existing SSH key on the bootstrap host and an account with noninteractive sudo. Verify each displayed fingerprint on its device with ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub. Passwords and private keys are never requested in this page.

Readiness & assisted fixes

Checks cover GB10 hardware, memory, storage, SSH, sudo, driver consistency, clock and fabric reachability. Package repairs run during installation.
